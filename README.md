
# FrcatalShirt
My Last Brain Cell as a fractal design


A Python-based generative  script that makes (Fermat's spiral) using the golden ratio.

## Fractal Type Implemented
* **Fermat's Spiral**: Generated using polar coordinates $r = c\sqrt{n}$ and $\theta = n \times 137.508^\circ$ (the golden angle) to mimic natural recursive arrangement patterns found in sunflower seeds and plant growth.

## Tools, Languages, and Libraries Used
* **Language**: Python 
* **Libraries**:
  * `numpy`
  * `matplotlib`
